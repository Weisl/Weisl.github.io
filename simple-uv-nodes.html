GEOMETRY NODES PACK · UV

SIMPLE UV Nodes

UV projection and transformation, live in your modifier stack. No unwrapping, no operators, no context switch — just drag a node in.

See It Update Live

Change a parameter, move the camera, edit the mesh upstream — the projection re-runs in real time, right in the Geometry Nodes editor.

Every Node, One Asset Library

Drag straight out of Blender's Asset Browser into your modifier tree — no installer, no Preferences toggle to hunt for.

Install in Four Steps

1. Download
Grab the release zip and extract it.
2. Pick Your Version
Choose the folder matching your Blender install, e.g. Simple_UV_Nodes_4_5.
3. Register the Library
In Preferences → File Paths → Asset Libraries, add that folder as a new Asset Library.
4. Drag & Drop
Open the Asset Browser, set it to Simple UV Nodes, and drag any node into your tree.
01
STAYS LIVE, STAYS PROCEDURAL

Non-Destructive
By Default

Blender's built-in UV projection tools live outside the modifier stack — run an operator, the result is baked, and any adjustment means starting over. Simple UV Nodes brings projection into Geometry Nodes so it stays live, adjustable, and procedural.

✓ Change any parameter at any time — nothing is baked until you need it to be
✓ Reacts automatically to upstream geometry changes
✓ No context switching — stay in the Geometry Nodes editor
02
DYNAMIC · WYSIWYG

See It in the Camera,
Get It in the UVs

Line up a real Camera object and the UVs match its view exactly — focal length and sensor size are read straight from the camera's data-block.

✓ Perspective or Orthographic — follows the camera's lens type, with true parallel projection when set to Orthographic
✓ Projection resolution set independently of the scene render resolution
Because it's a Geometry Nodes modifier, the projection stays dynamic — move or animate the Camera, or edit the mesh upstream, and the UVs re-project in real time.
03
BUILT FOR EVERY SURFACE

Planar, Spherical,
or Cylindrical

Pick the projection that matches the geometry — flat for floors and walls, seam-corrected spherical for round objects, or cylindrical with optional blended caps for pipes, columns, and anything else that revolves around an axis.

✓ Planar — flat projection for dominant-direction surfaces
✓ Spherical — normalized or real-world scale, seam-corrected
✓ Cylindrical — optional blended caps on end faces
04
INSTANCE & ISLAND RANDOMIZE

Break Up
Texture Tiling

Randomize offset, rotation, and scale for each instance or UV island to break up repetition. Ideal for scattered geometry, wood planks, or objects using repeating tileable textures.

✓ Instance Randomize — random UV transform per instance
✓ Island Randomize — random UV transform per UV island
05
AUTOMATE THE UV PIPELINE

Skip the Manual
Cleanup Pass

Automate the cleanup at the end of your modifier stack — mark UV seams as sharp edges, or pack the UVs onto a second channel for lightmaps, ambient occlusion, or texture masks.

✓ Mark Edges — turn UV island boundaries into seams and sharp edges automatically
✓ Pack to Channel — auto-pack islands into a second UV channel for lightmaps, ambient occlusion, or masks

All 11 Starter Nodes

Every projection, transform, and utility node in the pack.

UV Box Project
Triplanar blend from all three axes, with independent offset, rotation, and scale per face — Object or World space.
UV Planar Project
Flat projection along a chosen X, Y, or Z axis, with its own offset, rotation, tiling, and scale.
UV Spherical Project
Equirectangular wrap, seam-corrected on any pole axis. Real World Scale keeps texel density consistent with a neighboring projection.
UV Cylindrical Project
Wraps around a chosen axis, with optional blended caps on end faces past a face-normal angle threshold. Rotate shifts the seam.
UV Camera Project
Reads a real Camera's focal length, sensor size, and lens type — including true parallel projection in Orthographic. Updates live.
UV Transform
Non-destructively offset, rotate, scale, tile, and mirror any existing UV map — no re-projecting from scratch.
UV Instance Randomize
Seed-controlled offset, rotation, and scale per instance, pivoted on each UV island's center so placement stays predictable.
UV Island Randomize
The same per-instance randomization, scoped to UV islands on one mesh — stack both for rock piles and brick walls.
UV Mark Edges
Writes island boundaries to seams and/or sharp edges, with independent Clear toggles to replace or layer with existing marks.
UV Pack to Channel
Packs islands into a destination map for lightmaps — Exact Shape packing traces the real outline, not just a bounding box.
UV Attribute Transform
A pure-vector helper with no Geometry socket — offsets, rotates, and scales a UV coordinate inline inside custom node groups.

The Starter Kit

These 11 nodes cover the essential UV workflow — projection, transform, randomization, and cleanup. This is the first release: more UV node groups are planned and will be added in future updates to the pack.

Everything Inside

One library, the whole UV workflow.

Named UV Attributes
Every node targets a user-specified UV attribute name, so you can create and manage multiple UV maps on one mesh.
Object or World Space
Choose the coordinate space for projections to keep UVs stable under object transforms or locked to the world.
Pure Geometry Nodes
No Python dependency, no operator to run — everything is a standard Geometry Nodes modifier.

Minimum Blender version: 4.5. If you update to a new minor version, swap the registered Asset Library folder to the matching one from the zip — older folders keep working but won't include newer features.
