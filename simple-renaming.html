01
REPLACE, NUMBER, SEARCH & REPLACE

One Panel to
Rename Them All

Replace names and add sequential numbering, add prefixes and suffixes in one click, or run a full search-and-replace pass — with regex support and in-pattern case modifiers (\u, \l, \U, \L) for case transformations on the fly.

✓ Add prefixes and suffixes in one click — no retyping the whole name
✓ Select targets and rename them with sequential numbering, dynamic variables, and precise pattern matching
✓ Drop @-variables into any field to pull in the object, its collection, parent, file name, date, or your own custom slots
✓ Sync object names to their data-blocks — or rename linked mesh, curve, and light data to match
✓ Search and select objects by name pattern before you touch anything
✓ Full Regular Expression support for complex, pattern-based renames
02
TARGET SELECTION

Choose Exactly
What Gets Renamed

Filter by object type, then decide whether changes apply to your current selection or the whole scene — narrow things down before a single name changes.

✓ Filter to exactly the types you need: meshes, materials, empties, cameras, lights, curves, armatures, and more
✓ Toggle Only Selected to scope every operation to your current selection instead of the whole scene
✓ Use Search and Select to pre-select objects by name pattern before renaming
03
SORTING

Numbering That
Follows Your Order

Sequential numbering doesn't have to follow the outliner. Sort your targets by selection, alphabetically, or by axis position — or take direct control with the interactive Select in Renaming Order tool.

✓ Sort by Selection, Alphabetical, or Axis order, with a one-click reverse
✓ Select in Renaming Order: click objects or bones one by one in the viewport to set the exact numbering sequence, then confirm with Enter
@f_@t_object_@i
→ myfile_MESH_object_1432
@o object · @c collection · @p parent
@n number · @d date · @r random
04
RENAMING VARIABLES

Dynamic Names, Built
From @-Variables

Drop @-variables into any name field to pull in live data instead of typing it by hand — the object's own name, its collection, its parent, the current file, date, or a padded counter.

✓ @o object name, @c collection name, @p parent name, @a active object — reference exactly what's changing, automatically
✓ @n padded counter, @d date, @i time, @f file name, @r random string
✓ @h, @l, @b, @u1–@u3 — your own custom slots for high-poly, low-poly, bake cage, or any convention you use
✓ Combine variables with regular text in any field
05
PREFIX & SUFFIX

Add Prefixes and
Suffixes in One Click

The fastest way to tag a batch of objects — type a prefix or suffix once, add @-variables if you need them, and apply it to every selected object in a single click.

✓ Dedicated Add Prefix and Add Suffix fields, applied independently
✓ Combine with @-variables for dynamic tags — a collection name, a padded number, the current date
✓ Works alongside Numerate and Search and Replace in the same pass
06
SEARCH & REPLACE

Find Exactly What
You're Looking For

Search and Select finds objects by name pattern before you touch anything; Search and Replace rewrites the matching part of the name — both with optional Match Case and full regex.

✓ Full Regular Expression support for complex, pattern-based renames
✓ Regex case modifiers on captured groups — \u$1, \l$1, \U$1, \L$1 — e.g. \u$1 to capitalize just the first letter
✓ Match Case toggle for precise, case-sensitive matching
07
MORE

The Small Things
That Add Up

Trim characters off the end of a name, reorder existing numbering without a full rename, and keep object data in sync — the details that keep a scene tidy.

✓ Trim End of String — cut a fixed number of characters, e.g. to drop a stale ".001"
✓ Numerate — reorder existing numbering without a full rename
✓ Data Name from Object — sync mesh, curve, and light data names to their objects
✓ Six one-click case converters: UPPERCASE, lowercase, PascalCase, camelCase, snake_case, kebab-case
08
RENAME BY TYPE

Rename Anything,
By Type

Objects, materials, collections, Node Groups, Point Clouds, UV maps, and more — filter to exactly the types you need, and apply changes to everything or just your current selection.

✓ Toggle between Prefix and Suffix mode, and choose Only Selected Objects to scope the batch
✓ Save and reuse Type Presets across different projects and naming conventions

Small Tool, Big Impact!

Small addon, deep toolset.

@-Variables
Insert dynamic values anywhere in a name pattern — @o object name, @n padded counter, @f/@d/@i file and date info, plus user-defined @h/@l/@b/@u slots.
Built for Big Scenes
O(1) lookups replace linear algorithms, so scenes with 500+ objects rename significantly faster.
Custom Hotkeys
Clear before/after feedback on every rename, with shortcuts you can remap to fit your own workflow.
Keeping the Overview
A popup panel lists exactly what's been renamed after every operation — object by object — so you can review the results at a glance instead of hunting through the outliner.
