Simple Collider

Simple Collider adds dedicated tools for creating physics colliders in Blender, for use in game engines like Unreal, Unity, and Godot. It supports common collider types — Box, Sphere, Capsule, Convex, and Mesh — as well as more advanced operations like Auto Convex decomposition and Oriented Bounding Box generation.

Colliders can be created and adjusted directly in the 3D Viewport, in Object or Edit Mode, on full selections or specific parts of a mesh, using pre- or post-modifier mesh data.
