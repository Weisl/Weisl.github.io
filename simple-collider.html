01 WIDE SHAPE SUPPORT

Every Shape,
One Toolset

Pick the collider type that fits — see each one in action.

Box
Simple, efficient, covers a wide range of use-cases.
Sphere
The most efficient shape — defined mathematically, not by polygons.
Convex
Versatile and efficient, especially without native mesh collisions.
Convex Cylinder
A clean cylindrical convex shape for common manmade structures.
Mesh
The most accurate and most expensive shape — static objects only.
Re-Meshed
Voxelates complex geometry to remove unnecessary interior faces.
Capsule
Efficient and simple — the usual choice for character colliders.
K-DOP
14- or 18-DOP slabs — tighter than a box, cheaper than a full hull.
02
OBJECT & EDIT MODE

Whole Selections,
Individual Parts

Create colliders in Object or Edit mode, for an entire selection or specific parts of a mesh — including multi-object Edit mode. Choose pre- or post-modifier mesh data for full control.

✓ Per-object, per-selection, or per-loose-part generation
✓ World-aligned or object-aligned collisions for primitives
✓ Adjust creation settings live from the 3D Viewport
03
AUTO CONVEX DECOMPOSITION

Break Complex Meshes
Into Convex Hulls

Auto Convex decomposes complex, organic shapes — rocks, statues, rubble — into a set of convex colliders. Not a one-click fix for every asset, but built for exactly the geometry that resists simple shapes.

✓ Powered by the V-HACD library
✓ Windows, Linux, and macOS — including Apple Silicon
✓ Depth setting trades hull count against accuracy
04
ORIENTED MINIMUM BOX

The Tightest Box,
Automatically

An automatically-oriented box collider with the lowest possible volume — same output as a regular box collider, indistinguishable to the engine, just tighter around the mesh.

Implementation based on code by Iyad Ahmed, used with permission.
05
NAMING PRESETS

Name It Once,
Every Engine

Save naming settings as presets, switch between them per project, and share the preset files with your team. Ships with read-only UE-default and Unity presets — pin one to load automatically on startup.
06
CONVERT WORKFLOW

Mesh, Collider,
or Empty — Any Direction

Convert any mesh to a collider, or any collider back to a regular mesh object, complete with renaming and collection assignment. Convert to lightweight Empty objects for engines that support empty-based collision.
