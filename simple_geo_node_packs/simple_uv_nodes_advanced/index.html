Simple UV Nodes Advanced

An extension to the Simple UV Nodes pack that adds cylindrical, spherical, and camera-based projections, variation tools for breaking texture repetition, UV warping, mesh flattening into UV space, and utilities for normalising and packing UV maps into lightmap channels.

Every node follows the same conventions as the core pack: it writes to a named UV attribute, stacks with UV Transform, and requires no Python or operator to run.

Minimum Blender version: 5.1

Feature Overview

  • Cylindrical Projection: Wrap UVs around a chosen axis with optional blended cap projection on end faces.
  • Spherical Projection: Latitude/longitude projection for planets, domes, eyes, and any convex rounded surface.
  • Camera Projection: Project UVs from the point of view of any object — ideal for decals and baked projection setups.
  • Per-Island Randomize: Apply a stable random offset, rotation, and/or scale per UV island to break visible texture repetition on complex meshes.
  • Per-Instance Randomize: Same randomisation applied per geometry instance — essential for scatter workflows where every copy shows the same texture.
  • UV Warp / Distort: Displace an existing UV map with a procedural noise field for organic, aged, or hand-painted effects.
  • UV Flatten: Transform the mesh so that vertex positions match UV coordinates — unfolds geometry into UV space for debugging, UV-based scattering, and UV-space simulations.
  • UV Normalize: Remap all UV coordinates to fit inside the 0–1 range after warping or procedural transforms push them out of bounds.
  • UV Lightmap / Mask Pack: Repack a possibly overlapping UV map into a second non-overlapping channel ready for lightmap or mask baking.

Installation

Follow the same steps as the core Simple UV Nodes pack. Both packs can share the same Asset Library folder or be registered as separate libraries.

  1. Download the release zip and extract it.
  2. Pick the version folder that matches your Blender installation.
  3. In Blender, open Edit → Preferences → File Paths → Asset Libraries and add the folder as a new Asset Library.
  4. Open the Asset Browser, set the library to Simple UV Nodes Advanced, and drag any node into your Geometry Nodes modifier tree.

Node Reference

UV Cylindrical Project

Wraps UVs around a chosen axis. U follows the circumference (0–1 = full wrap), V follows the height along the axis. An optional cap mode adds a planar projection on end faces, blended by face-normal angle so the transition is smooth and controllable.

Typical use cases: pipes, columns, tree trunks, cables, bottles, any surface of revolution.

Input Type Default Description
UV Map String UVMap Name of the UV attribute to write
Coordinates Menu Object Coordinate space: Object or World
Axis Menu Z Cylinder axis: X, Y, or Z
Tiling Float 1.0 Uniform tiling multiplier
Offset Vector2 0, 0 UV translation offset
Rotate Float 0° Rotation around the axis — shifts the seam position
Scale Vector2 1, 1 Non-uniform UV scale
Caps
Enable Caps Boolean false Activates planar projection on end faces
Cap Blend Angle Float 30° Face-normal angle below which a face is treated as a cap
Cap Scale Vector2 1, 1 Scale applied to the cap planar projection

UV Spherical Project

Latitude/longitude (equirectangular) projection. U wraps around the equator (0–1 = full circumference), V runs from south pole to north pole. Rotating the projection around the pole axis shifts the prime meridian so the seam can be hidden on the back face.

Typical use cases: planets, domes, eyes, balls, any convex rounded surface.

Input Type Default Description
UV Map String UVMap Name of the UV attribute to write
Coordinates Menu Object Coordinate space: Object or World
Pole Axis Menu Z Axis pointing to the north pole: X, Y, or Z
Tiling Float 1.0 Uniform tiling multiplier
Rotate Float 0° Rotates projection around the pole axis — shifts the seam
Scale Vector2 1, 1 Non-uniform UV scale

UV Camera Project

Projects UVs from the point of view of a chosen object. The projector's local Z-axis defines the projection direction; U and V are derived from its local X and Y axes. Any object can act as a projector — point it at the surface and the texture appears painted on from that angle.

Typical use cases: decal-style placements, baked projection setups, gobo/spotlight texture projection.

Input Type Default Description
UV Map String UVMap Name of the UV attribute to write
Projector Object — Object whose local Z-axis defines the projection direction
Tiling Float 1.0 Uniform tiling multiplier
Offset Vector2 0, 0 UV translation offset
Scale Vector2 1, 1 Non-uniform UV scale
Clip Boolean false Faces outside the projector's forward hemisphere receive UV 0, 0

UV Per-Island Randomize

Reads each UV island, computes a stable random seed from it, and applies a randomised offset, rotation, and/or scale to every face in that island. Variation is consistent within an island and different across islands — tiling textures on complex meshes look non-repetitive without any texture re-authoring.

Typical use cases: rock piles, brick walls, foliage, cobblestones, any mesh where the same texture tile repeats visibly.

Input Type Default Description
UV Map String UVMap Name of the UV attribute to randomise
Seed Integer 0 Global seed — changing it reshuffles all islands
Offset
Randomize Offset Boolean true Enable per-island UV offset
Max Offset Vector2 1, 1 Maximum random offset in U and V
Rotation
Randomize Rotation Boolean false Enable per-island UV rotation
Max Rotation Float 360° Maximum random rotation angle
Scale
Randomize Scale Boolean false Enable per-island UV scale variation
Scale Min Float 0.8 Minimum scale factor
Scale Max Float 1.2 Maximum scale factor
Uniform Scale Boolean true Apply the same random factor to both U and V

UV Per-Instance Randomize

Applies a randomised UV offset, rotation, and/or scale per geometry instance. Where UV Per-Island Randomize works on UV islands within a single mesh, this node targets instanced geometry so that each copy of the same mesh samples a different region of the texture.

Typical use cases: scattered rocks, trees, debris, or tiles placed with an Instance on Points node — any scatter workflow where every copy currently shows the same texture.

Input Type Default Description
UV Map String UVMap Name of the UV attribute to randomise on instances
Seed Integer 0 Global seed — changing it reshuffles all instances
Offset
Randomize Offset Boolean true Enable per-instance UV offset
Max Offset Vector2 1, 1 Maximum random offset in U and V
Rotation
Randomize Rotation Boolean false Enable per-instance UV rotation
Max Rotation Float 360° Maximum random rotation angle
Scale
Randomize Scale Boolean false Enable per-instance UV scale variation
Scale Min Float 0.8 Minimum scale factor
Scale Max Float 1.2 Maximum scale factor
Uniform Scale Boolean true Apply the same random factor to both U and V

UV Warp / Distort

Displaces an existing UV map using a procedural noise field, shifting each UV coordinate by a noise-derived vector. The warp is applied on top of whatever projection is already in the UV attribute, composing naturally with any of the projection nodes in the pack.

Typical use cases: aged or weathered textures, water surface distortion, hand-painted look, breaking up perfectly tiling projections.

Input Type Default Description
UV Map String UVMap Name of the UV attribute to distort
Strength Float 0.1 Maximum displacement magnitude in UV space
Noise Scale Float 5.0 Spatial scale of the noise field — higher values produce finer detail
Noise Detail Float 2.0 Number of octaves in the noise
Noise Roughness Float 0.5 Roughness of the noise
Seed Integer 0 Noise seed — changing it reshuffles the distortion pattern

UV Flatten

Transforms the mesh so that each vertex position matches its UV coordinate — effectively unfolding the 3D mesh into UV space. U maps to X, V maps to Y, producing a flat representation of the UV layout as real geometry.

Because UV maps are stored per face-corner in Blender (not per vertex), vertices at UV seams naturally split — the mesh separates along seams exactly as it appears in the UV editor.

Typical use cases: UV debugging directly in the 3D viewport, UV-based scattering (scatter points on the flat mesh for precise UV-coordinate distribution), UV-space simulations.

Input Type Default Description
UV Map String UVMap Name of the UV attribute to use as position source
Factor Float 1.0 Blend between original 3D position (0) and UV-space position (1). Animating this creates a morph transition.
Scale Float 1.0 Uniform scale applied to UV coordinates before placing in 3D space
Z Offset Float 0.0 Height offset — lifts the flattened mesh off the world origin

UV Normalize

Remaps an existing UV map so that the bounding box of all UV coordinates fits inside the 0–1 range. Useful after UV Warp / Distort or procedural transforms push coordinates out of bounds, or to normalise a raw positional UV before feeding it into a texture.

Input Type Default Description
UV Map String UVMap Name of the UV attribute to normalise
Uniform Boolean true Preserve the U/V aspect ratio — the shorter axis is centred rather than stretched
Padding Float 0.0 Inset margin inside the 0–1 boundary after fitting

UV Lightmap / Mask Pack

Takes a primary UV map that may contain overlapping islands (e.g. mirrored geometry sharing a single-sided texture) and repacks all islands into a second, non-overlapping UV channel. The packed channel is ready for lightmap baking, ambient occlusion, or any texture mask where overlapping UVs produce incorrect results.

Input Type Default Description
Source UV Map String UVMap Name of the existing (possibly overlapping) UV channel
Output UV Map String LightmapUV Name of the new non-overlapping UV channel to write
Margin Float 0.02 Padding between packed islands in UV space (0–1)
Scale Float 1.0 Overall scale applied to all islands before packing

Tips

Cylindrical seam placement — Use the Rotate input on UV Cylindrical Project to spin the projection around its axis. Place the seam on a hidden edge (the back of a column, the underside of a pipe) before locking in the rest of the UV transform.

Spherical pole pinching — Pole pinching is inherent to equirectangular projection and most noticeable at low polygon counts. Increase mesh density at the poles or blend with a UV Planar Project on the cap faces to reduce the artefact.

Camera projection and object transforms — UV Camera Project reads the projector's world-space transform, so moving or animating the projector live-updates the UVs. Pin it with a Copy Location constraint if you want the projection to stay fixed after placement.

Combining randomise nodes — UV Per-Island Randomize and UV Per-Instance Randomize can be stacked. Apply Per-Instance first (to give each instance a unique base offset), then Per-Island on the realised mesh (to further vary individual islands within each instance).

Warp after projection — UV Warp / Distort operates on whatever UV values are already in the attribute. Chain it after any projection node to add organic distortion without losing the original projection setup.

UV Flatten for scatter — Flatten the mesh, run Distribute Points on Faces to scatter in UV space, then use UV Flatten with Factor 0 (or invert the transform) to bring scattered positions back into 3D space. This gives you pixel-perfect UV-coordinate-based distribution.

Lightmap margin — A Margin of 0.02–0.05 is standard for lightmap baking to prevent texel bleed between islands. Increase it for low-resolution bake targets (512×512 or smaller).

UV Map name — Every node's UV Map string socket must match the attribute name on the mesh exactly. Blender's default is UVMap. Check or rename it in Object Data Properties → UV Maps.
